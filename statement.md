# Project Statement

## Project Title

SpendWise – Student Expense & Budget Management System

## Domain

Python Essentials

## Problem Statement

I (and many of my friends) spend money almost every day on food, travel, books, entertainment etc. but we rarely write it down properly. By the end of the month it becomes difficult to know where the money went and whether we stayed inside our planned budget.

Most mobile apps need internet or force you to create accounts. I wanted a simple offline tool that runs in the terminal, saves data on the computer itself, and still shows useful summaries. That is why I built SpendWise for this course project.

## Scope of the Project

- Create and login with a student profile (name + email)
- Add, view, search, edit and delete expenses
- Set a monthly budget and see remaining amount
- Get category-wise and monthly spending reports
- All data is stored in a local SQLite database
- Only Python standard library is used (no external packages)

## Target Users

College / university students who want a quick way to track daily expenses without installing heavy apps.

## High-level Features

1. User profile management (create, login, update)
2. Full expense CRUD with categories
3. Monthly budget setting and status warnings
4. Simple analytics (total, by category, highest expense, monthly summary)
5. Input validation and basic error handling
6. Coloured terminal interface for better readability

## Technologies Used

- Python 3
- SQLite (built-in)
- Command Line Interface
- Git & GitHub
